# Insurance SQL Portfolio

This repository contains an insurance database portfolio project built with SQLite and Python. It includes schema creation, sample data generation, and example SQL queries for insurance-related analysis.

## Project Contents

- `schema/create_tables.sql` - SQL script to create the insurance database schema.
- `data_generation/populate_insurance_db.py` - Python script to generate and populate sample insurance data.
- `insurance.db` - Local SQLite database file containing the populated insurance data.
- `queries/basic_query.sql` - Example SQL query against the insurance schema.
- `analysis/` - Analysis artifacts related to portfolio exploration.
- `data/` - Data files used or generated for the project.
- `insurance-sql-portfolio-plan.md` - Project plan and notes.

## Purpose

This project is intended to:

- model an insurance dataset in SQLite
- generate realistic sample data programmatically
